Sherlock Home — Phase 6 Agentic Layer foundation

This package implements:
- canonical Phase 5 tool names in the security allowlist
- closed ToolRegistry
- ToolDispatcher with fail-closed runtime check and deterministic authorization
- strict tool argument adapters
- JSON-safe structured results (Decimal remains exact as string)
- strict JSON tool-plan parser
- safe model-visible tool metadata
- deterministic spending-reduction workflow
- FinancialAgent evidence orchestration
- tests for registry, dispatcher, planning, workflow, and agent boundaries

Deliberate boundary:
This package does NOT yet make a direct Ollama call for free-form chat planning or final prose.
The current public repository exposes app/agents/system_prompt.py but no dedicated model-planner
adapter under app/agents. FinancialAgent therefore accepts a FinancialPlanner protocol. This keeps
registry/dispatcher/security independent from model transport and lets the approved local Ollama
integration be wired next without changing the deterministic execution boundary.

No database or Alembic changes are included.

Apply from repository root:
    unzip -o sherlock-home-phase6-agentic-layer.zip -d .

Run:
    pytest -q tests/test_tool_registry.py tests/test_tool_dispatcher.py \
              tests/test_tool_planning.py tests/test_financial_workflows.py \
              tests/test_financial_agent.py
    pytest -q

Do not commit until the full suite is green.
