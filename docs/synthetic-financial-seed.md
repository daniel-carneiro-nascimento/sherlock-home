# Synthetic Financial Seed

This development-only seed creates deterministic synthetic financial activity
for two 14-day windows:

```text
2026-06-01 through 2026-06-14
2026-07-01 through 2026-07-14
```

It exists to exercise the real PostgreSQL-backed financial-analysis and agent
flow without importing a real bank statement.

The seed includes:

- salary income;
- housing;
- groceries;
- food;
- transport;
- utilities;
- health;
- shopping;
- leisure;
- transfers.

All data is fictitious.

## Seed the normal development database

From the repository root:

```bash
python -m scripts.seed_synthetic_financial_data
```

The command is idempotent through deterministic synthetic fingerprints.

Running it again should report the rows as skipped rather than duplicate them.

## Verify

```bash
docker compose exec postgres psql \
  -U "$POSTGRES_USER" \
  -d "$POSTGRES_DB" \
  -c "
SELECT
    date,
    amount,
    transaction_type,
    category,
    merchant
FROM transactions
WHERE date >= DATE '2026-06-01'
  AND date <  DATE '2026-08-01'
ORDER BY date, id;
"
```

Monthly summary:

```bash
docker compose exec postgres psql \
  -U "$POSTGRES_USER" \
  -d "$POSTGRES_DB" \
  -c "
SELECT
    DATE_TRUNC('month', date) AS month,
    transaction_type,
    COUNT(*) AS count,
    SUM(amount) AS signed_total
FROM transactions
WHERE date >= DATE '2026-06-01'
  AND date <  DATE '2026-08-01'
GROUP BY 1, 2
ORDER BY 1, 2;
"
```

## Remove only the synthetic seed

```bash
python -m scripts.seed_synthetic_financial_data --clear
```

The clear operation targets only the deterministic fingerprints generated by
this seed.
