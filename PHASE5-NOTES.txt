Sherlock Home — Phase 5 Financial Tools package

This ZIP contains only Python source/tests:

app/services/financial_analysis.py
tests/test_financial_analysis.py

It intentionally contains:
- NO SQLAlchemy model changes
- NO database schema changes
- NO Alembic migrations
- NO API route changes
- NO documentation changes

Implemented deterministic Phase 5 functions:
1. get_monthly_spending()
2. get_category_spending()
3. compare_monthly_spending()
4. find_recurring_expenses()
5. get_cash_flow()
6. detect_spending_anomalies()

Apply from repository root:

    unzip -o sherlock-home-phase5-financial-tools.zip -d .

Then run:

    pytest -q tests/test_financial_analysis.py
    pytest -q

Do not commit until the complete suite is green.

Important design choices:
- Money uses Decimal.
- Spending reports expose expense totals as positive analytical magnitudes.
- Transfers are excluded from spending and net cash flow.
- Category=None remains explicit.
- Spending comparison returns percentage_difference=None when the comparison period is zero.
- Recurrence detection is deterministic: grouping + interval range + amount tolerance.
- Anomaly detection is deterministic: prior merchant history, falling back to category history, with an explicit multiplier threshold.
- No LLM is used by any financial calculation.
